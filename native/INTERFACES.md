# anticraft-native cross-module interfaces

Data flow: `ui` <-> `app` (channels) -> `agent` -> `api` -> `auth`. `store`/`settings` are used by `app` (and `auth::store` reuses `store::atomic_write`).

## orchestration state fixes (shared signatures changed)

- `AppCommand::EditLastPrompt(String)` is now `EditLastPrompt(String, Option<AgentMode>)`: the one-shot `/plan` or `/fast` mode of the edited prompt is preserved. `ui::composer::submit` passes `edit_mode(original_text)` (new public fn in `ui::composer`). The backend's `TurnKind::Edit(String)` is now `TurnKind::Edit(String, Option<AgentMode>)`.
- `Agent::edit_last_prompt(text, events, cancel)` is now `Agent::edit_last_prompt(text, Option<AgentMode>, events, cancel)` and calls `run_prompt_with_mode` instead of `run_prompt` so a surviving `/plan` is not stripped twice.
- `Agent::steer_sender()` now returns `SteerHandle` (new public type in `agent::mod`) instead of `mpsc::UnboundedSender<String>`. `SteerHandle::send(text) -> bool` returns `false` once the turn closed its input, so the backend queues instead of losing the text. `SteerHandle::reopen()` is called by `run_prompt_with_mode`; `close()` by the same method when the turn ends. `take_pending_steer()` now calls `close_and_take()`.
- `orchestrate::store_artifact` now returns `Option<(PathBuf, ArtifactMeta)>` (the store's metadata, including the version it decided) instead of `Option<PathBuf>`. The agent's `OrchestrationState::record_artifact(name, summary)` is replaced by `apply_meta(meta, history_len)`, which takes the store's `ArtifactMeta` and the history position (for rollback). Without a store, a synthesized `ArtifactMeta` (version numbered after the previous in-memory one) is passed.
- `OrchestrationState::complete(result)` is now `complete(result, history_len)`; `completed()` returns `Option<&str>` as before. `OrchestrationState::roll_back(kept_history_len)` replaces the old truncate-only behavior: it drops artifacts written in the dropped turns, restores plan flags from the kept artifacts, clears tasks and the mode override, and drops a completion that was set in a dropped turn. Dropped artifacts are returned by `take_pending_artifacts()` so the backend deletes them from disk (`ArtifactStore::remove(name)`, new).
- `OrchestrationState::covers_plan` no longer counts an empty artifact list as covering the plan; `mutation_block` keeps the pending-plan gate even in Fast mode. `OrchestrationState::cancel_reviews()` clears `Pending` review states (Stop during a review pause). `OrchestrationState::reopen_tasks()` undoes the `Completed` that `task_complete` set, for steering after completion.
- `TurnDone` gains `steer: Vec<String>` (text the turn did not inject; runs as the next prompt) and `restore: Vec<ArtifactMeta>` (artifacts an edit/retry rolled back; the backend deletes them). `Backend` routes late steers into the queue in `turn_finished`.
- `ui::taskgroups::TaskUpdate { boundary, turn }` (new public struct) and `turn_of(items) -> usize` (new public fn) let `UiState` keep `AgentEvent::TaskUpdate`s and refine the derived task group cards via `apply_updates(&mut Derived, &[TaskUpdate])` (new public fn). `UiState` gains `task_updates: Vec<TaskUpdate>`.
- `orchestrate::edit_cut(items) -> Option<usize>` (new public fn) is the shared cut point for edit/resend; `ui::composer::submit` uses it instead of its own `rposition`. `orchestrate::resend_text(&Content) -> String` joins multiple text parts with a blank line instead of concatenating.
